Kotatsu_Sync.crx
Kotatsu Sync
Role
Developer — co-built with @nondotxyz
Stack
TypeScript - Vue - WXT - PeerJS / WebRTC - Cloudflare TURN
Status
Released — v0.2.2

A browser extension that syncs video playback between two people watching on animepahe, so you can watch together. The connection is peer-to-peer over WebRTC nothing relays the video itself, only the playback events.

I built the crossbrowser support for Chromium and Firefox, and the TURN server functionality that keeps syncing working when a direct peer-to-peer connection can't be made. It runs on Cloudflare TURN with credentials you supply yourself, so the extension never has to host or pay for relay infrastructure.

I also built the settings page where those credentials are entered and stored, plus the connection status badge and the connect/disconnect sounds, so you can tell the link is alive without opening the popup.
